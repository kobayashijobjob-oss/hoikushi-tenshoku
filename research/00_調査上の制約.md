# 調査上の制約（必読）

## 外部サイトへの直接アクセスが遮断されている

本プロジェクトの調査環境では、組織のegressポリシーにより
**外部ドメインへの直接アクセス（HTTPS CONNECT）が403で拒否**されている。

実際に拒否されたホストの例：
`developers.google.com` / `search.google.com` / `note.com` / `minhyo.jp` /
`hoiku.levwell.jp` / `www.suzukikenichi.com` ほか多数

→ 検証コマンド：`curl -sS "$HTTPS_PROXY/__agentproxy/status"` の `recentRelayFailures`

## これが意味すること

| 調査手段 | 可否 | 備考 |
|---|---|---|
| Web検索（検索結果のタイトル・スニペット・要約） | ✅ 可能 | 全調査はこれベース |
| 競合サイトの実ページ閲覧（文字数・見出し構成・CTA配置の実測） | ❌ 不可 | 検索結果からの推定のみ |
| Google検索セントラル等の一次情報の全文確認 | ❌ 不可 | 要約・二次情報経由 |
| ASP管理画面での実単価確認 | ❌ 不可 | 公開情報からの推定のみ |

## 結論：本 `research/` 配下の数値の扱い

**すべての検索ボリューム・単価・CVR/CTR・順位占有率は「公開情報ベースの推定」である。**
意思決定の方向性を決めるには十分だが、**実行前に以下の実地検証が必須**。

### 事業責任者が手元で必ず実施すべき検証（優先度順）

1. 🔴 **主要KWで実際にGoogle検索し、上位10件のURLを自分の目で確認する**
   （本調査の競合分析の前提が正しいかの検証。30分で済む）
2. 🔴 **ASP（A8.net / PRESCO / afb / アクセストレード）に登録し、管理画面で保育士案件の実単価・成果地点・承認条件を確認**
   → `research/03_monetization.md` の単価表を実数で上書きすること
3. 🟡 **ラッコキーワード／キーワードプランナーで実検索ボリュームを取得**
   → `research/02_keywords.csv` の `est_volume` 列を実数で上書き
4. 🟡 **上位競合3社の記事を実際に読み、文字数・見出し構成・CTA位置を記録**

**この4点が終わるまで、本調査結果は「仮説」であり「事実」ではない。**
戦略の方向性（どこを狙うか）は本調査で決めてよいが、
数値目標（何件で何円）は実数確認後に再計算すること。
