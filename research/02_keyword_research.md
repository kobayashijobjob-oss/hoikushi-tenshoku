## 0. サマリ

- 収集語数: **399語**（11クラスタ）。うちCV直結（A）180語、準ずる（B）139語、集客（C）80語。
- **結論1: 正面の収益KW（「保育士 転職サイト おすすめ」等）は6ヶ月では獲れない。** SERP 1〜10位が全てアフィリ比較ランキングで、20社〜73社比較の物量勝負になっている。初期投資先として不適。
- **結論2: 勝ち筋は新設クラスタ C11「採用側・選考突破」。** 競合の主力は人材紹介会社の自社メディアであり、彼らは構造上『園側の本音』を書けない。ここは**ボリュームが小さい代わりに競合が実質不在**で、かつ応募直前＝CV距離が最短。
- **結論3: 給料・資格・制度のヘッドKWはAI Overviewsに食われる。** 定義・指標系クエリのオーガニックCTRは31〜35%まで低迷する一方、ハウツー・プロセス系は平均63%を維持しているという調査がある。**本サイトは意図的に後者（体験・比較・意思決定）に寄せる。**
- **要判断事項: 「直接応募 vs 紹介会社」系KWは収益と利益相反する。** 第5章で別途フラグ。統括判断を仰ぎたい。

## 1. 調査方法と制約（重要）

### 1.1 実施したこと
- WebSearch による各クラスタのSERP実査（転職サイト比較／辞めたい・人間関係／給料・処遇改善／働き方・施設タイプ／ノウハウ／資格・キャリア／地域／評判／異業種／市場統計／採用側・選考突破／直接応募vs紹介／紹介手数料相場）。
- 上位表示ドメインの種別（アフィリ比較メディア／人材紹介の自社メディア／求人DB／資格スクール／官公庁／養成校）から競合タイプを判定し、推定難易度に反映。
- 上位記事のタイトル・見出しに出現する語の組み合わせから、実需のある複合KWを抽出。

### 1.2 できなかったこと（制約の明示）
> **本環境ではネットワーク制限により、Googleサジェストの直接取得（suggestqueries.google.com）、Bing/DuckDuckGo/Yahoo!のサジェストAPI、ラッコキーワード、および競合サイトのsitemap.xml直接クロールがすべてegress proxyにブロックされ、実行できませんでした。**
>
> したがって**本ファイルの検索ボリュームは、実測値ではなく推定値です。**Googleキーワードプランナー／ラッコキーワード／Ahrefs等での実測による検証を、着手前に必ず行ってください。

### 1.3 推定ボリュームの根拠ロジック（捏造防止のため明記）
各KWのボリュームは、以下の観測可能な代理指標から**レンジとして推定**しています。個別根拠は表の「推定根拠・備考」列に記載。

| 推定バケット | 割当の判断基準 |
|---|---|
| 10,000 | 1〜2語の業界ヘッドKW。専業メディアが複数、当該KW単体で専用ページを持つ |
| 5,000 | 2語の主要KW。大手10社以上が同一KWで記事を持ち、SERPが全て商用記事 |
| 1,000 | 2〜3語。専門メディア5社以上が記事を保有し、タイトルに完全一致で含む |
| 500 | 3語の複合。複数メディアが記事化済みだが、網羅記事の一部として扱われることも多い |
| 100 | 3〜4語。記事化しているのは1〜3社、または大手記事内の見出しレベルで存在 |
| 50 | 4語以上、または記事化ゼロ。実需はあるがコンテンツ供給が追いついていない領域 |

**バケット間の誤差は±1段階を想定してください。**特に50/100帯は「キーワードプランナー上は『検索なし』表示でも実際には月10〜50件の検索が発生しうる」領域であり、ツール実測でも過小評価されます。

## 2. 列の定義（凡例）

| 列 | 値 | 定義 |
|---|---|---|
| 推定Vol | 10,000 / 5,000 / 1,000 / 500 / 100 / 50 | 月間検索ボリュームの推定レンジ（**実測値ではない**／1.3節参照） |
| 意図 | Know / Do / Buy / Go | Know=知りたい、Do=やり方を知り実行したい、Buy=サービスを選びたい、Go=特定の場所・サイトへ行きたい |
| CV距離 | A / B / C | **A**=CV直結（求人応募・エージェント登録の直前）／**B**=準ずる（転職検討中で数クリック先）／**C**=集客・啓蒙（CVまで遠い） |
| 難易度 | High / Mid / Low | SERPの競合タイプから判定。High=大手アフィリ比較or求人DBが独占／Mid=専門メディアが複数/Low=競合が実質不在 |
| AI耐性 | 高リスク / 中 / 強い | **高リスク**=単純な事実・定義・数値回答でAI Overviewsに食われやすい／**強い**=体験・比較・意思決定でAIが代替しにくい |
| 優先 | 1〜50 | 新規ドメインが最初の6ヶ月で狙うべき50語の優先順位（第4章） |

### AI耐性の判定基準（第6章で詳述）
実査で確認した調査によると、**定義・指標系クエリのオーガニックCTRは31〜35%**に低迷する一方、**ハウツー・プロセス系クエリは平均63%を維持**しています。また、AI Overviewsが表示される場面では検索1位のCTRが62.7%低下、ゼロクリック検索の割合は63.5%に達したとの報告もあります（いずれも二次引用。第8章に出典）。
この差分を「AI耐性」列として3段階でフラグ化しました。

## 5. 【要判断】「直接応募 vs 紹介会社」系KWの利益相反

統括からの指示に基づき、該当KWを個別にフラグ化しました（CSVの `note` 列に `【利益相反フラグ】` を付与、計11語）。

### 5.1 実査で分かったこと

**ボリューム: 小さい（各50〜100と推定）。** ただし**意図は極めて強い**。
この語を打つ人は「紹介会社を使うべきか否か」を能動的に判断しようとしており、**転職行動の分岐点そのもの**にいます。

**競合: 実質不在＝完全な空白地帯。** SERPを実査した結果:
- 上位は**人材紹介会社の自社メディア**（保育士ワーカー、保育士人材バンク、ほいくis等）が占める。当然ながら結論は「紹介会社を使うべき」に寄っており、**ポジショントーク**になっている。
- もう一方の上位群は**保育園の採用担当者向けB2B記事**（紹介料金比較、採用単価削減）で、求職者向けではない。
- **つまり「求職者の立場から、園側のコスト構造を踏まえて中立に解説した記事」が存在しない。**

### 5.2 何が衝突するのか

| | 内容 |
|---|---|
| 事実 | 紹介手数料は理論年収の**30〜35%**（年収350万円で約**105〜122万円**）。園はこれを採用時に負担する |
| 読者にとっての含意 | 同条件の候補者なら、園は直接応募者を選ぶ動機がある。つまり**紹介経由は選考で不利になりうる** |
| サイトの収益構造 | 収益は紹介会社への送客（1成約8,000〜10,000円）。**上の含意を強く書くほど収益が減る** |
| 放置した場合 | 読者が後から手数料の存在を知れば「園長なのに黙っていた」＝**ポジションの信頼性が根本から崩れる** |

### 5.3 推奨スタンス（統括の承認を求めます）

**「隠さない。ただし紹介会社を否定もしない」**という設計を推奨します。具体的には:

1. **手数料の存在と相場は明記する。** ここを伏せると園長を名乗る意味がなくなる。透明性こそが本サイトの資産。
2. **『紹介経由＝不利』と断定しない。** 実際、園の判断は分かれる（採用計画・予算・欠員の緊急度で変わる）。これは事実として正確であり、同時に収益とも両立する。
3. **読者の利益を最大化する着地にする。** すなわち**「手数料を上回る納得材料を選考で示せば不利にならない。その示し方はこれだ」**として、C11の選考突破記事へ繋ぐ。
4. **使い分けの基準を提示する。** 例: 在職中で時間がない／非公開求人を見たい → 紹介会社が有利。行きたい園が既に決まっている／小規模園や公立志望 → 直接応募が有利。**これは実態としても正しく、読者に誠実。**
5. **収益導線は「否定しない記事」側に置く。** 利益相反記事そのものにCTAを詰め込まない。

> **統括へ: 上記1（手数料の明記）は収益に対する短期的なマイナスを伴います。ここを許容するかどうかが、本サイトのポジショニングが本物になるかの分岐点だと考えます。判断をお願いします。**
> また、公開前に**表現の法務チェック**（特定の紹介会社への信用毀損にならないか）を推奨します。

## 6. AI Overviews / AI検索への耐性フラグ

### 6.1 判定の根拠
実査で確認した公開調査（いずれも二次引用・第8章に出典）:
- AI Overviews表示時、検索1位のCTRが**62.7%低下**（Ahrefs調べの引用）
- ゼロクリック検索の割合が**63.5%**に到達との報告
- 2026年4月時点で全クエリの**約48%**にAI Overviewsが表示（前年比58%増）
- **定義・指標系のオーガニックCTRは31〜35%**に低迷、一方**ハウツー・プロセス系は平均63%を維持**

### 6.2 「食われやすい」KW（高リスク・66語）

単純な事実・定義・数値で答えが確定するもの。**流入前提で記事を作ると裏切られる。**
典型: 給料/手取り/年収の数値、処遇改善手当の金額、資格の取り方、幼稚園教諭との違い、面接の服装、配置基準、有効求人倍率、退職届の書き方。

**方針:**
- これらを**主力記事にしない**。作る場合も「数値を答える記事」ではなく、**「その数値が自分の場合どう変わるか」を判断させる記事**に変換する。
  - ✕「処遇改善手当はいくら？」 → ○「処遇改善手当が明細に載っていない時、園に何をどう聞くか」

## 7. 最初の6ヶ月で狙うべき50語（優先順位つき）

### 7.1 選定基準
統括の追加指示を受け、**「採用側視点で独自性を出せるか」を第1評価軸**として再選定しました。

## 8. サイト構造への示唆（次工程への引き継ぎ）

キーワードマップから導かれる構造案:

```
トップ（現役園長が運営する保育士転職メディア）
├── 【ピラー】選考突破ガイド（C11）★中核
│    ├── 面接（逆質問／落ちる理由／園長が見るところ／保育観）
│    ├── 書類（志望動機／職務経歴書／転職回数の書き方）
│    ├── 園の見極め（見学チェック／ブラック園／離職率の調べ方／求人票の読み方）
│    └── 応募経路（直接応募 vs 紹介／手数料の構造）★要法務・統括確認
├── 【ピラー】辞めたい・悩み（C2） → C11へ送客
├── 【ピラー】働き方・施設タイプ比較（C4） → 求人送客
├── 【ピラー】給料・処遇改善の実態（C3） ※ヘッドは避け運用実態に特化
├── 【ピラー】転職の進め方（C5） ※園の採用カレンダー視点
```

**設計上の要点:**
1. **C11をトップから1クリックの位置に置く。** ここがサイトの主張であり、内部リンクの重心。

4. **AI耐性『高リスク』のKWは下層に配置し、内部リンクのハブにしない。** 流入が構造的に減る前提で設計する。
