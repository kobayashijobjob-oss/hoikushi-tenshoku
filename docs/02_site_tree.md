## 2. 構造から意図的に「外した」もの（重要）

削るのは足すより重要な意思決定なので、理由を明記する。

| 外したもの | 理由 | 根拠 |
|---|---|---|
| **地域別求人ページの量産**（/tokyo/ 等） | Scaled Content Abuse の典型。2024年3月に「自動生成か人力かを問わず」へ文言強化 | `research/04` 地雷5 |
| **求人情報の掲載・転載機能** | 職安法上「募集情報等提供事業」に該当し的確表示義務・最新性保持義務が発生 | `research/04` |
| **口コミ投稿機能／他社口コミの転載** | 名誉毀損＋著作権の二重リスク。収益寄与ゼロ | `research/04` 地雷4 |
| **園・法人の実名評判（C8 15語）** | 上記に加え、園長という立場上の業界内レピュテーションリスク | `research/02` §5 |
| **「保育士 面接 質問」等のヘッドKW単独狙い** | ①事業者が100%占有。派生KW経由でのみ取りに行く | `research/01` F2 |
| **「保育士 求人 東京」「保育士 派遣」等のナビ系ヘッド** | 求人DBを持たない第三者は構造的に勝てない（占有率0%） | `research/01` F2 |
| **メルマガ/LINEでの求人配信** | 職安法43条の2「特定募集情報等提供事業」の届出義務が発生 | `research/04` 地雷1 |
| **「No.1」「満足度○%」等の表示** | 改正景表法（2024年10月施行）で直罰化。措置命令は広告主に飛び、提携解除で跳ね返る | `research/04` 地雷3 |
| **お祝い金・ギフト券の企画／特集** | 募集情報等提供事業者への金銭提供禁止が2025年4月1日施行済み | `research/04` 地雷2 |
| **中古ドメインの取得** | Expired Domain Abuse | `research/04` 地雷5 |

## 3. 内部リンク設計：評価をどう流すか

新規ドメインの限られた評価を、**意図的に一方向へ流す**。

```
     ┌──────────────────────────────────────────────┐
     │  【集客】nayami（辞めたい・つらい）            │  ← 検索流入の母数
     │   読者状態：感情的・まだ動けない                │
     └───────────────┬──────────────────────────────┘
                     │ 「辞める」と決めた瞬間に必要になるもの＝退職理由の伝え方
                     ▼
     ┌──────────────────────────────────────────────┐
     │ ★【中核】recruit-inside（採用のウラ側）        │  ← 権威性の源泉 かつ CV engine
     │   読者状態：行動開始。武器を求めている          │
     │   D.紹介会社のウラ側 ／ C.園の見極め            │
     └───────────────┬──────────────────────────────┘
                     │ 「どうやって園を探すか」が次の問い
                     ▼
     ┌──────────────────────────────────────────────┐
     │ 【選択】hatarakikata ／【条件】kyuyo            │  ← 選択肢の提示
     └───────────────┬──────────────────────────────┘
                     ▼
     ┌──────────────────────────────────────────────┐
     │ 【収益】service（比較）／ 各記事内のCTA         │  ← 送客
     └──────────────────────────────────────────────┘
```

### リンクの原則

1. **上位カテゴリのピラーへは全配下記事から必ずリンク**（クラスタの結束）
2. **nayami → recruit-inside への送客を全記事に必ず1本**（感情→行動の橋渡し）
3. **recruit-inside → service への直リンクは M12 まで張らない**
   理由：評価の薄い /service/ に流すと中核の評価が希釈される。
   M1-M11のCVは**記事内CTAで直接ASPへ送る**
4. **クラスタを跨ぐ横リンクは原則禁止**（例：kyuyo → nayami）。トピックの境界を曖昧にしない
5. **リンクは文脈内に置く。記事末の「関連記事」羅列に依存しない**

## 4. CV（収益）の着地点マップ

| カテゴリ | 読者状態 | 主力案件 | 想定単価 | 優先度 |
|---|---|---|---|---|
| **recruit-inside/D 紹介会社** | 紹介会社を使うか検討中 | 転職エージェント（面談型） | 8,000〜30,000円 | ★★★ |
| **recruit-inside/C 園の見極め** | 応募直前 | 転職エージェント（登録型） | 2,200〜5,000円 | ★★★ |
| **recruit-inside/A・B 選考突破** | 応募中 | 転職エージェント | 同上 | ★★ |
| hatarakikata/雇用形態 | 派遣・単発を検討 | 派遣登録・スキマバイトアプリ | 3,000〜8,000円 | ★★ |
| nayami/退職の実務 | 辞めたいが言い出せない | 退職代行 | 3,000〜10,000円 | ★★ |
| kyuyo | 年収を上げたい | 転職エージェント | 同上 | ★ |
| service（M12〜） | サービスを比較中 | 転職エージェント | 同上 | ★★★（M12〜） |

**設計上の要点：中核カテゴリ（recruit-inside）が、権威性の源泉であると同時に最大のCVエンジンである。**
選考突破の情報を求めている読者＝応募直前であり、CV距離が構造的に最短だから。
これが「権威性への投資」と「収益」が一致する、この設計の最大の長所。
