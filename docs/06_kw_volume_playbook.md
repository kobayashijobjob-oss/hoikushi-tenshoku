# キーワード実ボリューム取得 手順書

> **目的：検証すべきは「優先順位の並び」ではなく「需要規模が目標に足りるか」。**

---

## 1. なぜこれが最優先なのか

優先50語の推定ボリュームは **50〜500** が中心です。

```
仮に優先50語すべてで1位を取れたとして
  50語 × 平均300 × CTR 30% ＝ 月4,500セッション
目標は                          月32,000セッション
                                 ↑ 目標の 14%
```

**優先50語を完璧に取り切っても、目標には届かない計算になります。**

これは戦略が間違っているという意味ではありません。優先50語は
「新規ドメインが最初に勝てる場所」として選んだものであり、
**収益の規模を作る層は別にある**はずだからです。

検証すべき問いはこれです：

> **Q. C11（採用側）を中核に据えたまま、
>    全399語を取り切れば月32,000セッションに到達できるのか？**
>
> - 到達できる → 現計画のまま進む
> - 半分程度 → クラスタを拡張するか、高単価比率を上げて必要セッションを下げる
> - 大きく不足 → **戦略の前提そのものを見直す**

この判定を、記事を書き始める前に済ませます。

## 2. ツール選定（初期投資 5〜20万円の制約下での推奨）

| ツール | 費用 | 用途 | 推奨 |
|---|---|---|---|
| **Googleキーワードプランナー** | 無料（要Google広告アカウント） | ボリュームの一次ソース | ◎ 必須 |
| **ラッコキーワード** | 月 約1,000円〜 | サジェスト網羅・関連語の発掘 | ◎ 推奨 |
| Ubersuggest | 月 約3,000円〜 | 簡易な難易度指標 | △ 任意 |
| Ahrefs / SEMrush | 月 2万円〜 | 被リンク分析・精緻な難易度 | ✕ **今は不要** |

**推奨スタック：キーワードプランナー（無料）＋ ラッコキーワード（月1,000円程度）。**
月額1,000円で足ります。Ahrefsに月2万円払うのは、記事が100本たまってからで十分です。
**今その2万円を使うなら、独自アンケートの謝礼に回すほうがリターンが大きい。**

### ⚠️ キーワードプランナーの落とし穴

広告を出稿していないアカウントでは、ボリュームが
**「100〜1,000」「1,000〜1万」のような広いレンジ表示**になり、精度が出ません。

**回避策**：Google広告で**少額キャンペーンを作成し、数百円〜1,000円程度消化**すると
多くの場合、詳細な数値表示に切り替わります。
（配信は即停止してよい。ボリューム精度のためだけの投資）

本手順書の集計スクリプトは、**レンジ表記の場合は下限値を採用**します（保守的に見積もるため）。
レンジのままでも判定はできますが、**精度を上げたいなら少額出稿を推奨**します。

## 3. 手順

### Step 1. キーワードを流し込む

用意済みのシードリストを使ってください（コピペするだけ）。

| ファイル | 語数 | 用途 |
|---|---|---|
| `tools/kw_seed_all.txt` | **399語** | **本番。これを使う** |
| `tools/kw_seed_top50.txt` | 50語 | 少額出稿での精度検証用の最小セット |

**キーワードプランナーでの操作：**
1. Google広告 → ツールと設定 → **キーワードプランナー**
2. 「**検索のボリュームと予測のデータを確認する**」を選択
3. `tools/kw_seed_all.txt` の中身を全文コピーして貼り付け（399語は1回で通ります）
4. 「開始する」→ **過去の指標** タブを開く
5. 右上のダウンロードアイコン → **CSV** で保存

### Step 2. マージして判定する

ダウンロードしたCSVのパスを指定して実行するだけです。

```bash
python3 tools/merge_volume.py ~/Downloads/Keyword\ Stats.csv
```

文字コード（キーワードプランナーはUTF-16）や、TSV/CSVの違いは自動判別します。
ラッコキーワードやUbersuggestのCSVでも、「キーワード」列と「ボリューム」列があれば動きます。

**出力されるもの：**
- `research/02_keywords_actual.csv` — 実測値で上書きした新しいKWデータ
- 標準出力に：
  - **需要規模フィジビリティ判定**（✅到達可能 / ⚠️不足 / 🔴規模不足）
  - **クラスタ別の実測ボリューム**（どの層に需要が偏っているか）
  - **推定から大きくズレた語 トップ20**（＝我々の読み違い。最も学びが大きい部分）

CTRの仮定を変えたい場合：
```bash
python3 tools/merge_volume.py <file> --ctr 0.20
```

### Step 3. 結果を共有する

判定結果の出力をそのまま貼ってください。それを受けて：

- ✅ 到達可能 → 計画は変えず、**クラスタ別ボリュームに応じてM1〜M6の本数配分を調整**
- ⚠️ 不足 → **拡張候補クラスタの選定**（C6資格／C9異業種／C7地域）と収益単価の引き上げ策を出す
- 🔴 規模不足 → **戦略の前提から組み直す**。目標額か期間、あるいは領域そのものを再設計

## 5. 補足：ラッコキーワードの使い方（関連語の発掘）

キーワードプランナーは「こちらが渡した語」のボリュームしか返しません。
**我々がまだ知らない語**を拾うには、ラッコキーワードでサジェストを取得します。

推奨する取得起点（この8語から始めれば大半を網羅できます）：

```
保育士 転職 / 保育士 辞めたい / 保育園 見学 / 保育士 面接
保育士 人材紹介 / ブラック保育園 / 保育士 求人票 / 保育士 志望動機
```

取得したサジェストのうち **399語のリストに無いもの** を抽出し、
Step 1 に追加して再測定してください。
特に **C11（採用側）クラスタ** は我々が新設した軸なので、
ラッコで拾える語がまだ埋もれている可能性が高い層です。
