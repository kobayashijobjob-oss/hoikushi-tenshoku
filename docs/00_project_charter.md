## 1. 目標の定義（Objective）

| 項目 | 内容 |
|---|---|
| 最終目標 | アフィリエイト収益 **月30万円** |
| 事業形態 | 保育士・幼稚園教諭向け転職情報メディア（第三者メディア） |
| 収益モデル | 成果報酬型アフィリエイト（転職サービス送客）を主軸、周辺案件で補完 |
| 想定到達時期 | **12〜18ヶ月**（新規ドメインのSEO立ち上がり遅延を織り込み） |

### 目標の分解（この数字を常に意識する）

```
月30万円
 = 年間360万円
 = 人材紹介会社1社が保育士を「4〜5人」決定させたときの手数料に相当（後述）
```

**この「小ささ」が最大の勝機である。** 我々は市場を取る必要はなく、
巨大な資金が流れているパイプから 0.01% を分岐させればよい。

## 2. 市場構造の理解（Why this market）

### 2-1. 需要サイド：構造的な人手不足＝終わらない転職需要

| 指標 | 数値 | 出典 |
|---|---|---|
| 保育士就業者数 | 約 **59万人** | 厚生労働省「保育士の現状と主な取組」 |
| 保育士登録者数 | 約 **167万人**（令和2年） | 厚生労働省 令和4年版厚生労働白書 |
| 潜在保育士（有資格・未就業） | 約 **102万人**（登録者の約60%） | 同上 |
| 離職率（全体） | **9.3%** ／ 私立 **10.7%**・公立 5.9% | 厚労省 |
| 年間離職者数（推計） | 約 **5.5万人／年** | 59万人 × 9.3% |
| 有効求人倍率 | **3.88倍**（2026年1月・全国平均） | 保育士バンク／職業安定業務統計 |
| 全職種平均 有効求人倍率 | 1.18倍 | 同上 |
| 退職理由1位 | 「職場の人間関係」**33.5%** | 厚労省「保育士の退職理由」調査 |

**示唆：**
- 有効求人倍率3.88倍は全職種平均の**3.3倍**。求職者が圧倒的に有利な売り手市場＝
  「転職を煽る」必要がない。**背中を押すだけで成立する**マーケット。
- 年間5.5万人の離職者＋102万人の潜在保育士プール。読者供給は枯れない。
- 退職理由1位が「人間関係」（33.5%）＝**検索の入口は「求人探し」ではなく「悩み」**。
  ここがコンテンツ戦略の急所（後述 §4）。

### 2-2. 供給サイド：なぜ高単価が成立するのか

| 指標 | 数値 | 出典 |
|---|---|---|
| 人材紹介手数料（保育士） | 想定年収の **20〜40%** | 業界各社公開情報 |
| 金額換算 | 1件あたり **約65万〜130万円**（平均80万円超） | 福岡県経営協 調査ほか |
| 保育士の平均年収 | 約326.8万円（令和2年 賃金構造基本統計調査） | 厚労省 |

**示唆：**
- 広告主（人材紹介会社）は1名の就業決定で **80〜100万円** を得る。
  ゆえに「無料登録1件」「面談1件」に **数千円〜数万円** を払う経済合理性がある。
- これは金融・不動産に次ぐ**高単価アフィリエイト領域**。低PVでも金額が立つ。
  → **我々の戦略は「PVを稼ぐ」ではなく「CVに近い読者だけを集める」**。

### 2-3. ざっくりTAM（媒体側の取り分）

```
年間の人材紹介経由 就業決定数（推計 2〜4万件）
  × 手数料 80万円
  = 人材紹介市場 1,600億〜3,200億円規模（保育領域）
      ↓ うちデジタル獲得予算を 10% と仮置き
  = 160億〜320億円／年 が Web 集客に投下
      ↓ 我々の目標 360万円／年
  = 市場シェア 0.001〜0.002%
```
※就業決定数・デジタル比率は当社推計（要検証）。手数料は出典あり。

**結論：市場規模は問題にならない。問題は「競合が強すぎる中でどう可視領域を確保するか」だけ。**

## 3. 想定される最大の敵（Key Risk）

先に結論を書く。このビジネスの失敗要因は「市場がない」ことではなく、以下である。

| # | リスク | 内容 |
|---|---|---|
| R1 | **SERPの事業者占有** | 上位は人材紹介会社の自社オウンドメディアが占拠。第三者比較記事が入る余地が年々縮小 |
| R2 | **Googleポリシー** | ヘルプフルコンテンツ／サイトの評判の不正使用。E-E-A-Tなき量産メディアは淘汰済み |
| R3 | **AI検索（AI Overviews / AI Mode）** | 「〜とは」型の情報KWはゼロクリック化。従来型の網羅記事は資産にならない |
| R4 | **立ち上がりの時間差** | 新規ドメインは初期6ヶ月ほぼ無風。ここで折れるのが最頻の死因 |
| R5 | **法規制** | 職業安定法（募集情報等提供事業）、ステマ規制（景表法）、No.1表示規制 |

→ R1〜R5 の実地検証を専門チームに並行発注済み（`research/01`〜`04`）。
   本憲章は各チームの報告を受けて v1.0 に更新する。

## 4. 初期仮説（検証対象）

調査結果が出る前に、あえて仮説を立てておく。検証の軸を持つため。

**H1｜勝ち筋は「悩み起点」であり「比較起点」ではない**
「保育士 転職サイト おすすめ」は事業者と強豪アフィリが占拠済み。
一方、退職理由1位の「人間関係」（33.5%）をはじめとする
**悩み・不満・不安のロングテール**は、検索意図が深く、事業者メディアが
自社ポジション上「本音を書けない」領域。ここに第三者メディアの構造的優位がある。

**H2｜E-E-A-Tは「コスト」ではなく「参入障壁」である**
保育士有資格者の実体験・独自アンケート・一次データは、
AIにも大手にも量産できない。ここに投資した分だけ堀になる。

**H3｜PVではなくCVから逆算する**
月30万円は「月100万PV」ではなく、
**「月20〜30件の成果 × 1万円前後」で到達しうる**（要検証：`research/03`）。
必要なのは大量の読者ではなく、**転職を決意した直後の読者**。

**H4｜地域×条件のロングテールが最後の取り分**
「保育士 転職 ○○市」「企業内保育 求人 ○○」等は競合が薄く、
CV意図が極めて濃い。ただし量産はポリシー違反リスクと表裏（要検証：`research/04`）。

## 6. 意思決定原則（Operating Principles）

1. **数字で判断する。** 「なんとなく良さそう」で記事を書かない。全記事にKWと想定CVを紐付ける。
2. **量より配置。** 100本の凡庸な記事より、正しい10本と正しい内部リンク。
3. **法務は最初に閉じる。** 後から直すのは10倍高い。ステマ表記・運営者情報は公開日から完備。
4. **6ヶ月は収益を見ない。** 見るのは「インデックス数・順位分布・クリック率」。
5. **一次情報に投資する。** 独自アンケート／実体験は、AIにも競合にもコピーできない唯一の資産。
