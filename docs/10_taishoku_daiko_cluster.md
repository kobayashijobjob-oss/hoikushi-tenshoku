# 退職代行クラスタの評価と位置づけ

> 起案：経営者（2026-09-23）「保育士 退職代行 あたりが狙い目。そこから転職に繋げる」
> 検証：本書
> **判定：採用する。ただし「転職への橋」ではなく、独立した高単価クラスタとして位置づける。**

---

## 1. 結論

| 論点 | 判定 |
|---|---|
| 勝てるか | **○** 「保育士 × 退職代行」の掛け算は、両側の競合が構造的に踏み込めない空白 |
| お金になるか | **◎** 単価が転職案件の **2.4〜3.9倍**。ただしCVRは未知（§4のリスク） |
| 転職への橋になるか | **△** 直接の導線にはならない。**ただし橋は1本だけ存在する**（§3） |
| 園長視点が効くか | **◎◎** 本プロジェクトの独自性が**最も強く効く領域**。中核クラスタに次ぐ |

---

## 2. 単価：転職案件の2.4〜3.9倍

| 案件 | 単価 | ASP |
|---|---:|---|
| 退職代行EXIT | **17,600円** | バリューコマース（独占案件） |
| 退職代行Jobs | 13,241円 / 12,000円 | バリューコマース / もしも |
| 弁護士法人みやび | 11,000円 | — |
| （比較）保育士転職 主力3案件の実効単価 | 4,545円 | A8ほか |

**成果条件：「webからの退職代行依頼。実際に依頼され支払いがあった場合のみ承認。」**

### 損益分岐CVR ― この1点だけが論点

無料登録（転職）より、3〜5万円の有料サービス申込（退職代行）のほうがCVRは必ず低い。
**では、どこまで低くてよいのか。**

| 案件 | 単価 | **必要CVR比** |
|---|---:|---:|
| 退職代行EXIT | 17,600円 | 転職登録CVRの **26%** を超えれば勝ち |
| 退職代行Jobs | 13,241円 | **34%** |
| 退職代行Jobs（もしも） | 12,000円 | **38%** |
| 弁護士法人みやび | 11,000円 | **41%** |

**転職登録のCVRが4%なら、退職代行のCVRが1.0〜1.6%あれば収益で上回る。**
高い壁ではない。**退職代行を検索する読者は、緊急度が最大の層**だからである。

---

## 3. 「転職への橋」は成立するか ― 正直な評価

### 経営者の構想：退職代行 → 転職

**直接の導線としては成立しにくい。** 理由は時間差。

```
退職代行を検索する読者の状態 ＝「今すぐ辞めたい」
転職の意思決定が起きるのは  ＝「辞めた後、数週間〜数ヶ月後」
```
同一セッションで2つ目のCVは起きない。Cookie（もしも90日）で拾える可能性はあるが、
**読者が再訪する前提の設計は脆い。**

### ただし、橋は1本だけ実在する ― 在職証明書

調査中に、この構想を成立させる唯一の接点が見つかった。

> **「退職代行を使うと在職証明書をもらいにくくなる。
>   転職する場合、必ず次の就業先に前の園の在職証明・在籍証明を提出しないといけない。」**

この1点が、**退職代行と転職を同一記事内で自然に接続する唯一の論点**である。

| 要件 | 評価 |
|---|---|
| 退職代行検討層が必ず不安に思うか | ◎ 「辞めた後どうなるか」の最大の実務不安 |
| 園長にしか書けないか | ◎◎ **在職証明書を発行するのは園長本人** |
| 転職行動に直結するか | ◎ 次の園に提出が必要な書類だから |
| 競合の状況 | **競合性指数 5**（実測済み。ほぼ空白） |
| 退職代行CTAと転職CTAを同時に置けるか | ◎ **この記事だけが両方を自然に置ける** |

→ **旗艦記事を確定：「退職代行で辞めたら、在職証明書はどうなるのか」**
（実測KW：`保育士 転職 在職証明書` Vol 20 / CPC 928円 / 競合性指数 5）

Vol 20 は小さい。**だがこれは集客記事ではなく、クラスタの結節点として置く。**
退職代行クラスタと中核クラスタの両方から内部リンクを集める、構造上の要になる。

## 4. リスク ― 採用にあたって直視すべき4点

### リスク1｜「大手は退職代行を書けない」は誤り

当初の私の仮説は**部分的に間違っていた。** 実際には書いている。

| サイト | 内容 |
|---|---|
| **レバウェル保育士**（人材紹介大手のオウンドメディア） | 「保育士が退職代行を使うとどうなる？メリット・デメリットや円満な辞め方」 |
| ほいとも（保育士転職メディア） | 「利用前に**『頼れる存在』に相談！**」＝自社への誘導 |

**ただしポジションは残っている。** 彼らが書けるのは「メリット・デメリット」「円満な辞め方」までで、
顧客が保育園である以上、**「使っていい」とは言えない**。論調が構造的に抑制される。

### リスク2｜競合の性質が違うだけで、激戦区ではある

「大手が寡占していない＝空いている」ではない。**別種の競合がいる。**

| 競合タイプ | 例 |
|---|---|
| 退職代行アフィリ専業サイト | 退職代行の教科書、退職代行ナビゲーター、セカステ 等 |
| 弁護士・サービス提供者自身 | 弁護士法人みやび |
| 法律系メディア企業 | アシロ（tenshoku.asiro.co.jp） |
| 人材紹介オウンドメディア | レバウェル保育士 |

**我々の勝ち筋は「保育士 × 退職代行」の掛け算にある。**
退職代行専業サイトは保育現場の内情を書けず、保育メディアは退職代行を推せない。
**両方の隙間**にしか、我々の記事は成立しない。ここを外すとどちらにも負ける。

### リスク3｜立場のねじれ

園長監修メディアが「退職代行を使え」と言うのは、論理的にねじれる。

**解決策：推奨しない。証言する。**

> ✕「保育士におすすめの退職代行3選」（＝他サイトと同じ。しかも立場が矛盾する）
> ◎「**退職代行の連絡を受けた園長側で、実際に何が起きたか**」

推奨より証言のほうが強い。読者は判断材料を受け取り、自分で決める。
**これは中核クラスタ（園長視点）の思想と完全に一致している。**

### リスク4｜承認率が未知

`research/03` で確認済みのとおり、**発生65万円で承認率2%という実例がこの業界にある。**
退職代行は成果条件が「実支払い」であり、キャンセル・不成立による否認が起きうる。

→ **D-008の運用ルールを適用：提携初月は少額テスト。承認率が判明するまで主力CTAに据えない。**

## 5. サイト構造への反映

現行のツリーマップ（`docs/02_site_tree.md`）では、退職代行は
`/nayami/ 退職の実務` の一項目に埋もれている。**これを格上げする。**

```
【集客】辞めたい・つらい /nayami/
 │
 ├─★ 退職の実務・退職代行  /nayami/taishoku/     ◀ 独立サブカテゴリへ格上げ
 │    ├ ピラー：保育士が辞めるとき、園側で実際に何が起きているか
 │    ├ 退職代行の連絡を受けた園長側で、何が起きたか        ★証言型
 │    ├ 【旗艦】退職代行で辞めたら、在職証明書はどうなるのか  ★★橋
 │    │     └─▶ /recruit-inside/ へ（中核クラスタへの唯一の自然な導線）
 │    ├ 退職代行を使ったことは、次の園に伝わるのか（園長のネットワークの実際）
 │    ├ 年度途中に辞めるのは本当に迷惑なのか（採用側の本音）
 │    ├ 引き止めの断り方／即日退職／バックレとの違い
 │    └ 退職代行を使う前に、園長として言っておきたいこと
 │
 └─（以下、既存のとおり）
```

**CV設計：**

| 記事 | 第1CTA | 第2CTA |
|---|---|---|
| 退職代行の証言型記事 | 退職代行（EXIT / Jobs） | — |
| **在職証明書（旗艦）** | **退職代行** | **転職エージェント** ← 両方置ける唯一の記事 |
| 年度途中／引き止め | 退職代行 | 転職エージェント |
| 辞めた後・再就職 | 転職エージェント | — |

## 7. 決定事項

- **採用する。** 退職代行クラスタを `/nayami/taishoku/` として独立サブカテゴリに格上げ
- **位置づけは「転職への橋」ではなく「独立した高単価クラスタ」**
- **橋は「在職証明書」記事1本に集約する**
- **トーンは推奨ではなく証言**（園長監修との整合／中核クラスタとの思想の一致）
- バリューコマース登録をM0タスクに追加（EXIT独占案件のため）
