# ポジショニング戦略 v0.1（仮説）

> 前提条件の確定（2026-09-21 事業責任者ヒアリング）
> - **当事者性：運営者の配偶者が現役の保育園 園長**
> - 制作キャパ：月20本以上（外注活用可）
> - 初期投資：5〜20万円／6ヶ月

## 1. 結論：我々は「採用する側」のメディアになる

### サイトコンセプト（案）

> **「園長が教える、保育士の転職」**
> ― 採用する側から見た、受かる人・落ちる人・選んではいけない園 ―

## 2. なぜこれが勝ち筋なのか（構造的な説明）

### 2-1. この市場の情報は、すべて「片側」からしか書かれていない

保育士転職の検索結果を占拠しているのは、人材紹介会社の自社オウンドメディア
（保育士バンク、マイナビ保育士、保育士ワーカー、ジョブメドレー等）である。

**彼らの顧客は誰か？ 保育園である。**

```
人材紹介会社のビジネスモデル
  保育園 ──(手数料 65〜130万円/件)──> 人材紹介会社
                                          ↑ 無料で利用
                                       保育士（求職者）

  → 保育園＝顧客。保育士＝在庫。
  → ゆえに「園にとって不都合な真実」は絶対に書けない構造。
```

彼らが書けないこと：
- 「その園、紹介手数料80万円払ってでも人が採れない理由があるかもしれません」
- 「紹介会社経由の応募は、園側の期待値が上がる（80万円分の期待）」
- 「園見学でここを見れば、辞める人が多い園かどうか分かる」
- 「その志望動機、園長は見抜いています」

**これらは全部、園長にしか書けない。そして検索需要は確実にある。**

### 2-2. E-E-A-T の観点：Experience の質が桁違い

Googleが最も評価する E-E-A-T の "E"（Experience = 実体験）において、
我々が持てるのは **「採用実務の当事者」** という希少な立場である。

| 情報の出し手 | Experience の質 | 書ける範囲 |
|---|---|---|
| 人材紹介会社のメディア | 紹介実績（伝聞） | 園に不都合なことは書けない |
| 一般的なアフィリエイトサイト | なし（二次情報の再構成） | 何でも書けるが信用されない |
| 元保育士のブログ | 就業経験（求職者側） | 自分の体験談まで |
| **我々** | **現役園長＝採用決裁者** | **選考側の本音＋園の内部事情** |

さらに：**AIには絶対に生成できない情報である。** AI検索時代に残る資産はここしかない。

### 2-3. 「園長ネットワーク」という二次的資産

園長は同業の園長・保育士とのネットワークを持つ。これは以下に展開できる：
- **独自アンケート**（例：現役園長50人に聞いた「採用したい保育士の条件」）
- **現役保育士へのインタビュー**（転職体験談の一次取材）
- **一次データのプレスリリース化**（被リンク獲得の正攻法）

一次データは、被リンクを自然に集める唯一の合法的手段である。

## 3. 差別化の設計：3つのコンテンツ層

```
┌─ 層1：園長視点コンテンツ（独占領域・被リンクと指名検索の源泉）
│   「園長が面接で見ているポイント」「園見学のチェックリスト」
│   「紹介会社経由の応募を園はどう見るか」「採用されない履歴書の特徴」
│   → 競合ゼロ。ここが我々のブランドを作る。
│
├─ 層2：悩み起点コンテンツ（集客の主戦場・CVへの導線）
│   「辞めたい」「人間関係」「サービス残業」「持ち帰り仕事」
│   → 退職理由1位＝人間関係(33.5%)。読者の絶対数が最大。
│   → 園長視点で「それは園を変えれば解決する／しない」を判定できるのが強み。
│
└─ 層3：転職サービス比較（収益化の着地点）
    「保育士 転職サイト おすすめ」等
    → 競合最激戦。単独では勝てない。
    → 層1・層2からの内部リンクで「評価を持ち込んで」戦う。
```

**重要：層3に直接突っ込んではいけない。** 新規ドメインで最激戦KWに挑むのは自殺行為。
層1で権威性を作り、層2で流入を作り、その評価を層3に流し込む。順序が全て。

## 4. ペルソナ（暫定）

| # | ペルソナ | 状況 | 検索行動 | 収益化距離 |
|---|---|---|---|---|
| P1 | **限界ちゃん**（20代後半・私立認可） | 人間関係で消耗、辞めたいが罪悪感 | 「保育士 辞めたい 人間関係」 | 中（まず共感→比較へ） |
| P2 | **条件改善型**（30代・経験5年以上） | 給料・残業に不満、次は失敗したくない | 「保育士 転職 失敗しない」「企業内保育 給料」 | **高（最重要）** |
| P3 | **復職検討型**（30-40代・潜在保育士） | ブランク不安、パート/時短希望 | 「保育士 ブランク 復帰 怖い」 | 中〜高（102万人プール） |
| P4 | **新卒/1年目** | 就活・初年度の離職 | 「保育士 1年目 辞めたい」 | 低〜中（単価は出るが迷いが長い） |

**主戦場は P2（条件改善型）。** 転職意欲が固まっており、
「失敗したくない」＝**情報を深く読む＝園長の意見を最も必要とする層**。
ここに園長コンテンツを当てるのが、本戦略の中核。

## 5. 想定される反論と回答

**Q. 園長の身内がやっていると明かして、保育士読者は引かないか？**
A. むしろ逆。「敵情視察」的な価値で読まれる。ただし**トーンが決定的に重要**。
   「園長目線で保育士を評価する（上から目線）」ではなく、
   **「採用側の内情を明かして、保育士の武器にしてもらう」**という編集方針で一貫させる。

**Q. 配偶者が園長だと、特定の園の批判が書けないのでは？**
A. 個別の園名は元々書かない（名誉毀損リスク・`research/04`で検証中）。
   書くのは「見分け方の一般則」。むしろ園長の知見はここで最大に活きる。

**Q. 監修表記で本人が特定されるリスクは？**
A. 実名・園名を出さない匿名監修（「現役保育園園長（保育士歴◯年）監修」）から開始。
   E-E-A-T上は実名が望ましいが、**リスクと便益を見て段階的に判断**する。
   → 事業責任者と要相談（Open Issue）。
